# HabitFlow — трекер привычек

Десктопное приложение на Python для отслеживания ежедневных привычек.

## Возможности

- ➕ Добавление и удаление привычек
- ✅ Отметка выполнения (двойной клик или ПКМ)
- 📊 Статистика по месяцам (отметки, процент, серия)
- 📅 Календарь текущего месяца
- 📈 График прогресса за месяц
- 🌙 Светлая и тёмная темы
- 💾 Хранение данных в SQLite
- 🔒 Работает без интернета

## Технологии

- **Python 3.10+**
- **tkinter/ttk** — графический интерфейс
- **SQLite** — база данных
- **matplotlib** — графики

## Установка и запуск

1. Клонировать репозиторий:

   git clone https://github.com/yaroslavzaxarov115-dot/HabitFlow.git
   cd HabitFlow

2. Установить зависимости:

   pip install -r requirements.txt

3. Запустить:

   python main.py
