# HabitFlow — трекер привычек

Десктопное приложение на Python для отслеживания ежедневных привычек.

## Возможности

- ➕ Добавление привычек
- ✅ Отметка выполнения (двойной клик или ПКМ)
- 📊 Статистика: серия, процент за 30 дней, всего отметок
- 🌙 Светлая и тёмная темы
- 💾 Хранение данных в SQLite

## Технологии

- **Python 3.10+**
- **tkinter/ttk** — графический интерфейс
- **SQLite** — база данных
- **matplotlib** — графики (в разработке)
